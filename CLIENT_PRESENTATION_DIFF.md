## 4. Déploiement Local & Mise en Ligne sur Vercel

Le projet a été pensé pour un déploiement instantané, sans configuration complexe :

### A. Test Local Immédiat
Le serveur local est actuellement actif sur votre machine :
```bash
http://127.0.0.1:3000/
```
Pour relancer à tout moment :
```bash
npm run dev
```

### B. Déploiement sur Vercel (en 2 minutes)
1. Téléversez le dossier du projet ou connectez votre dépôt GitHub à [Vercel](https://vercel.com).
2. Vercel détecte automatiquement le projet avec `package.json` et `vite.config.js`.
3. Le fichier `vercel.json` inclus configure automatiquement :
   - Les URLs propres sans extension `.html` (`/`, `/votre-coach-et-sophrologie/`, etc.)
   - Les redirections des anciennes URLs (`/about-me/` -> `/votre-coach-et-sophrologie/`, etc.)
   - Les en-têtes de sécurité recommandés en 2026.
4. Cliquez sur **Deploy** : le site est en ligne avec un score de performance maximal et une disponibilité mondiale par CDN.
